## Principal contract cho B1/C1/D1

Đầu vào ở **API adapter** dùng Spring `@AuthenticationPrincipal Jwt` (không import
Identity infrastructure). Jwt đã được Spring decoder validate algorithm/signature/
issuer `gdrn`/audience `gdrn-spa`/time/claim shape trước controller:

```java
UUID actorId = UUID.fromString(jwt.getSubject());
String actorRole = jwt.getClaimAsString("role"); // CITIZEN hoặc AUTHORITY ở route đã allowlist
```

Truyền UUID và role value đã map vào input/application của module; không truyền Jwt,
Authentication, HTTP request hay SecurityContext vào application/domain. Role không
đọc từ body/query. Các owner có thể map string sang enum nội module/use-case flag;
không cần import domain/internal Identity. Đây là adapter convention, không Java
cross-module provider mới. B1 thực thi report ownership bằng actorId; security route
allowlist chỉ bảo vệ role, không thay object ownership. C1/D1 cùng convention.

Người 1 thêm method/path allowlist khi feature thực sự merge; hiện E03–E15 vẫn deny.
Không dùng `permitAll('/api/**')` để vượt dependency. Token unsupported role không có
GrantedAuthority và trả403; missing/invalid token401. E02 lấy user hiện tại từ DB;
account mất hoặc role khác claim =>401. Không user deletion/role management trong MVP.

## Convention frontend cho owner khác

Owner tạo `frontend/src/features/<feature>/routes.tsx` khi page thật sẵn sàng:

```tsx
import type { FeatureRoute } from '../../app/feature-routes'
import { ReportsPage } from './ReportsPage'
export const routes: FeatureRoute[] = [
  { path: '/my-reports', label: 'Báo cáo của tôi', roles: ['CITIZEN'], element: <ReportsPage /> },
]
```

Router glob imports file export này, reject duplicate paths, tự bọc RoleGuard và
hiển thị nav theo role. Page API errors vẫn phải xử lý tại feature; guard không thay
backend. `landingPath` tự chuyển CITIZEN tới S03/AUTHORITY tới S04 khi route tương ứng
đã có. **P01 chưa có hai route đó**: S01 hiện card identity thật + logout tại `/login`,
không giả report/operations screen, không thêm màn hình business thứ bảy.

- HTTP: `api<T>('/api/...', {method, body: JSON.stringify(payload), signal})` từ
  `src/shared/api.ts`; no cookie, Bearer từ memory, no automatic retries. ApiError
  có status/problem/code/fieldErrors; 403/409 giữ session, 401 của current session clear.
- Auth: `useSession()` đọc user/expiry; `session.clear()` logout. Feature component
  tree remount theo generation để bỏ local state; cache ngoài component đăng ký
  cleanup qua `session.onClear(callback)` và unsubscribe khi không dùng nữa.
- Components `Field` (label/id/error), `Loading`, `ErrorMessage`, `EmptyState` trong
  `src/shared/components.tsx`; global CSS đã có form/button/card/notice/focus styles.
  Giữ role/label accessible, không copy auth/API client/global CSS vào feature.
- Dependency/router config/lockfile do Người 1 điều phối; owner dùng `npm ci`, ghi
  yêu cầu package hoặc shared patch trong handoff. Không commit node_modules/dist.
