## HTTP contract cho C2/B3

| API | Quyền | Thành công | Lỗi nghiệp vụ chính |
| --- | --- | --- | --- |
| E10 `PATCH /api/reports/{id}/verification` | AUTHORITY | 200 Report mới sau atomic write | 404 NOT_FOUND; 409 INVALID_TRANSITION / DISASTER_NOT_ACTIVE |
| E11 `DELETE /api/reports/{id}` | CITIZEN owner | 204, body rỗng | 404 missing/đã rút/khác owner; 409 report không PENDING hoặc thua race |
| E08 `GET /api/reports` | CITIZEN own; AUTHORITY all | 200 page | 400 nếu bộ tọa độ/bán kính thiếu hoặc sai |

E10 verify: `{"status":"VERIFIED","disasterId":"<canonical UUID từ E03/E05>"}`.
E10 reject: `{"status":"REJECTED","rejectionReason":"Lý do 1–500 code points"}`.
Hai shape loại trừ nhau; null/field dư/sai case/expectedVersion bị 400. E11 không có
body/query. Không gửi version nội bộ, reporterId, role hoặc timestamp.

Report PENDING chỉ có common fields B1. VERIFIED thêm disasterId/verifiedAt;
REJECTED thêm rejectionReason/rejectedAt. Field không áp dụng bị bỏ hẳn, không null.
Không expose version, withdrawnAt hoặc geography. Timestamps UTC/microseconds;
updatedAt bằng thời điểm decision; rejectionReason strip hai đầu trước validation.

E08 ví dụ:

```text
GET /api/reports?lat=21.028&lon=105.834&radiusMeters=1000&status=PENDING&type=FLOOD&page=0&size=20&sort=createdAt,desc
```

Nhận đủ lat/lon/radiusMeters hoặc bỏ cả ba; tọa độ hữu hạn trong WGS84, bán kính
integer 1–100000m, inclusive distance ≤ radius. Filter AND với ownership/status/type/
disasterId trước DB count/page. Sort có id ASC tie-break. Count/items cùng snapshot;
report đã rút không xuất hiện qua single/list/batch dù người gọi là authority.

401/403 theo shared JWT policy; JSON shape/query/limits → 400 VALIDATION_ERROR;
media sai → 415; lỗi DB/ngoài dự kiến → 500 INTERNAL_ERROR. Response/error no-store.
Không tự retry mutation ở UI; refetch sau 409 rồi để người dùng quyết định.

## Race và check-time rule

Command authorize → đọc visible report → kiểm tra PENDING → (verify) đọc Disaster
ACTIVE mới → atomic UPDATE theo id/version/PENDING/withdrawn_at IS NULL. Zero affected
rows → 409 INVALID_TRANSITION. Initial read missing/withdrawn → 404; khác owner
→ 404 trước xét state. Không nhận expectedVersion qua HTTP E10/E11.

Hai caller cùng đọc PENDING: verify/verify, verify/withdraw hoặc withdraw/withdraw
đều chỉ một bên thành công, bên thua 409. Retry sau commit withdrawal có thể nhận
404. Resolve trước eligibility query chặn verify; resolve sau query vẫn cho phép
verify commit. Không hứa ACTIVE-at-commit hay giữ lock xuyên module.

## Published contract cho D1

Các type public trong `com.gdrn.reporting.application.contract`, framework-independent:

```java
public interface ReportingQuery {
    Optional<ReportSnapshot> findById(UUID reportId);
    Map<UUID, ReportSnapshot> findByIds(Set<UUID> reportIds);
}
public record ReportSnapshot(UUID id, UUID reporterId, ReportState status,
                             Optional<LinkedDisaster> disaster) {}
public record LinkedDisaster(UUID id, LinkedDisasterState status) {}
public enum ReportState { PENDING, VERIFIED, REJECTED }
public enum LinkedDisasterState { ACTIVE, RESOLVED }
```

Spring bean `ReportingQuery` đã wire. D1 tạo port riêng của Rescue; infrastructure
adapter inject interface trên, map snapshot về kiểu của Rescue. Application/domain
Rescue không import Reporting internals. Query là trusted internal; D1 tự kiểm tra
reporterId khi phục vụ citizen E14.

- Missing/withdrawn → Optional.empty; batch bỏ key, không tombstone/deleted flag.
- Chỉ VERIFIED có linked disaster; trạng thái ACTIVE/RESOLVED đọc mới qua port.
- Tối đa 100 distinct IDs; null input/member hoặc >100 → IllegalArgumentException.
- Empty set → immutable empty map, không query DB; kết quả/DTO immutable.
- Một report batch SQL + tối đa một distinct Disaster batch; không N+1/cache.
- VERIFIED reference bị mất → failure toàn vẹn; DB failure propagate, không giả absence.
