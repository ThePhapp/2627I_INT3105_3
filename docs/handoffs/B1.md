# B1 — tạo/xem report và ownership

Tích hợp 09/10/2026. B1 gốc `5ff284a` đã được hòa giải với kế hoạch duy nhất trên
main `a195093` và C1 `766cf1f`. Các blocker migration/security trong handoff ban đầu
đã được xử lý; xem [kết quả tích hợp](B1-C1-integration.md).

## Đã triển khai

- Domain Report/Coordinates plain Java: PENDING, UUID owner, type, description
  strip/nonblank/1–2000 Unicode code points, latitude [-90,90], longitude [-180,180],
  số hữu hạn, UTC timestamps. Không Spring/JPA/HTTP trong domain.
- Application ReportService → ReportStore port. Principal Jwt tại API adapter được
  map thành ReportActor (UUID + CITIZEN/AUTHORITY), không nhận owner/role từ body.
  Citizen chỉ tạo/xem của mình; authority chỉ đọc. Khác owner/missing cùng404.
- JdbcReportStore explicit data mapper: geography(Point,4326), longitude trước
  latitude, UUID và timestamptz. Không cross-module FK/join hoặc gọi Rescue.
  [ADR 007](../adr/007-reporting-postgis-data-mapper.md); không thêm root dependency.
- E08 page 0–1000000; size 1–100/default20; createdAt asc/desc + id ASC; filters
  status/type/disasterId AND tại DB. Count/items cùng REPEATABLE READ snapshot;
  test chèn dữ liệu giữa hai query chứng minh không lệch snapshot.
- DTO độc lập persistence. Query lạ/lặp, ownerId/reporterId, UUID không canonical,
  JSON dư/null/field giả, limits sai bị400. Success/error no-store và ApiError chung.

## API/consumer

| API | Role | Consumer | Success | Errors |
| --- | --- | --- | --- | --- |
| E07 POST /api/reports | CITIZEN | S02 / Người 2 | 201 Report | 400,401,403,415,500 |
| E08 GET /api/reports | CITIZEN own; AUTHORITY all | S03/S04/S06 | 200 PageResponse | 400,401,403,500 |
| E09 GET /api/reports/{id} | CITIZEN owner; AUTHORITY | S03/S04/S06 | 200 Report | 400,401,403,404,500 |

Body E07:

```json
{"type":"FLOOD","description":"Water rising near the entrance","latitude":21.028,"longitude":105.834}
```

Response mẫu (IDs minh họa, dùng IDs từ API khi thử thật):

```json
{
  "id":"00000000-0000-4000-8000-000000000005",
  "reporterId":"00000000-0000-4000-8000-000000000001",
  "type":"FLOOD",
  "description":"Water rising near the entrance",
  "latitude":21.028,
  "longitude":105.834,
  "status":"PENDING",
  "createdAt":"2026-10-09T03:00:00Z",
  "updatedAt":"2026-10-09T03:00:00Z"
}
```

List: `GET /api/reports?page=0&size=20&sort=createdAt,desc&status=PENDING&type=FLOOD`.
Page shape `{items,page,size,totalElements,totalPages}`; empty dataset có totalPages=0,
page vượt cuối có items=[] nhưng count giữ đúng. Không metadata geometry/JPA/mission.
Swagger đã ghép [B1 slice](../api/b1-adapter-contract.json) qua resource reporting.json;
baseline P00 vẫn là 15 operations, runtime chỉ E01–E09.

## Migration/security đã tích hợp

V4__reporting_reports.sql được cấp sau V3 C1 trong [ledger](../architecture/phase1-module-contracts.md).
Không còn SQL nháp phải chạy bằng tay. Flyway tạo schema, không seed, không sửa V1–V3.
Production SecurityConfiguration chỉ mở POST collection cho CITIZEN và GET collection/
single report cho CITIZEN/AUTHORITY. Test-only security chain và manual schema setup
đã bỏ; ReportingIT chạy decoder/HTTP/Flyway/policy production với PostGIS Testcontainers.
Bootstrap tests giữ auth/default-deny coverage và assert chính xác 9 operations/6 paths.
V3→V4 upgrade test giữ nguyên user/disaster có sẵn và rerun không áp thêm migration.
