- E08: page 0–1000000; size 1–100/default20; sort createdAt asc/desc + id ASC.
  status/type/disasterId AND tại DB trước count/page. Count/items cùng snapshot
  REPEATABLE READ; concurrent insert giữa hai câu SELECT đã có test thật.
- Tất cả B1 reports PENDING, chưa liên kết disaster. Filter VERIFIED/REJECTED/disasterId

## Contracts, statuses và payload

[P00](../api/phase1-contract.yaml) giữ nguyên baseline 15 operations.
[B1 adapter slice](../api/b1-adapter-contract.json) là OpenAPI 3.0.3 hợp lệ với đúng
E07/E08/E09, sáu query parameters đã thực thi, response chỉ PENDING. Đây chưa phải
runtime Swagger: controller có `@Hidden` vì route production vẫn default deny.
Runtime hiện tiếp tục công bố E01/E02 đúng P01; không quảng cáo B1 đã usable.

| API | Owner | Consumer | Success | Errors khi tích hợp policy |
| --- | --- | --- | --- | --- |
| E07 POST /api/reports | Người 2 / B1 | Người 2 / S02 | 201 Report | 400, 401, 403, 415, 500 |
| E08 GET /api/reports | Người 2 / B1; spatial B2 | S03, S04, S06 | 200 PageResponse | 400, 401, 403, 500 |
| E09 GET /api/reports/{id} | Người 2 / B1 | S03, S04, S06 | 200 Report | 400, 401, 403, 404, 500 |

Ví dụ body E07 (không chứa reporterId/status/thời gian/role):

```json
{"type":"FLOOD","description":"Water rising near the entrance","latitude":21.028,"longitude":105.834}
```

Ví dụ response 201 (IDs minh họa, thay bằng kết quả thật):

```json
{
  "id":"00000000-0000-4000-8000-000000000005",
  "reporterId":"00000000-0000-4000-8000-000000000001",
  "type":"FLOOD",
  "description":"Water rising near the entrance",
  "latitude":21.028,
  "longitude":105.834,
  "status":"PENDING",
  "createdAt":"2026-10-09T03:00:00Z",
  "updatedAt":"2026-10-09T03:00:00Z"
}
```

List ví dụ: `GET /api/reports?page=0&size=20&sort=createdAt,desc&status=PENDING&type=FLOOD`.
Page luôn `{items,page,size,totalElements,totalPages}`, page vượt cuối có items=[]
nhưng totalElements giữ count thực; dataset rỗng có totalPages=0. DTO không có geometry,
entity metadata, mission, password/email hay verification fields null.
Success/error dùng no-store. Error shape dùng ApiError chung, không phản chiếu input.
